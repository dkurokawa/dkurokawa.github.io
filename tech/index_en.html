paper-pipeline running

6-stage pipeline / medallion data lake

A document-processing platform that collects documents at volume, decomposes them, and structures, verifies and synthesizes them stage by stage.

  • All four inference stages run on local LLMs at home. External API cost is zero
  • The lake is a medallion of bronze (raw) → silver (structured) → gold (ready to serve), designed and implemented by me
  • Layers live in R2, processing state in a PostgreSQL state machine. Data and progress kept separate
  • At ingest, related documents are gathered and passed to an LLM to synthesize consensus, contradictions and gaps (batch RAG). Query-time generation is left downstream
  • The exit is an embedding-based search API. Nine resident workers and a watchdog

Two-stage hybrid inference on vehicle dashboards

Browser ONNX + server GPU / taken on personally, in slack time at work

Inference that reads vehicle instrument-panel images, built in two stages.

  • A first pass in the browser on ONNX (YOLOv8, 5.8MB); only the images it can't settle go to the server GPU
  • Against sending everything to the GPU, that cuts the work substantially
  • 95.0% on 882 validation images with a confusion matrix. 94.9% (±2.4) when re-measured with 5-fold splits grouped by ar_id
  • It ran on a phone, but never went to production
